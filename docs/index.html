Chat without an account.

Sign in with a key file. Messages are encrypted in your browser, so the server only relays data it cannot read.

Open app View source

End-to-end encrypted

ECDH key exchange and AES-GCM messages. Encryption happens in your browser, so the server only relays ciphertext.

ECDH P-256 · AES-GCM

Key file login

No email, phone or password. An optional password can protect the file.

Stories

Images that expire after 12 hours, visible to everyone or selected people.

Local history

Optional, encrypted, and stored only on your device.
